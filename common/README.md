# 공통 메뉴 데이터

Pretuning의 데이터 형식을 유지하며 레몬 아이스티 → 레몬티, 말차라떼 → 녹차라떼만 이름을 변경했다. 기존 11개 항목과 카테고리 구조를 유지한다. 레몬티와 레몬차는 동일한 공식 레몬차에 매핑되지만 사용자 요청대로 항목을 합치지 않았다.

- `menu_data.py`: 메뉴·카테고리·속성. PRICE_OPTIONS는 조회한 실제 가격 집합으로 갱신했다. 기존 3000~8000원/500원 간격은 새 가격과 맞지 않는다.
- `menu_prices.json`: 기존과 같은 메뉴명 → 정수 원화 형식.
- `menu_price_sources.json`: 가격별 출처와 확인일. 공식 홈페이지는 가격을 표시하지 않아 정자엠코점 패스오더 가격을 사용했다. 에스프레소만 SSG 모바일쿠폰 판매가격을 참고했으며 매장 가격과 동일함을 보장하지 않는다. 전국 공통 공식 가격표가 아니다.
- `menu_images.json`: 메뉴명 → HOT/COLD → 웹 이미지 경로. 키가 하나인 메뉴는 그 온도만 제공한다.
- `menu_image_sources.json`: 공식 상품명, 온도별 원본 이미지 URL, 공식 페이지와 확인일.
- `../frontend/public/images/menus/`: 공식 사이트에서 내려받은 원본 이미지 14개. 레몬티/레몬차는 파일을 공유한다. 브라우저에서는 `/images/menus/...` 경로로 사용한다.

현재 Dockerfile은 public 폴더를 복사하므로 기존 컨테이너는 frontend 이미지를 재빌드해야 새 자산이 반영된다. 새 필드는 기존 메뉴/가격 파일에 끼워 넣지 않고 별도 JSON으로 제공한다.

가격 정규화가 기존 3000~8000원 범위를 가정하는 Pretuning 코드와 재결합될 경우 새 PRICE_OPTIONS의 최솟값·최댓값을 사용해야 한다. 현재 브랜치에는 해당 추천 실행 코드가 없다.

- 브랜드 로고·색상·글꼴과 출처는 brand_assets.json, 프론트 적용 기준은 ../docs/frontend-design.md에 기록했다. 로고는 frontend/public/images/brand에 있다.

- menu_display.json: 프로젝트 초기 간편 메뉴 4종과 순서. 공식 인기/추천 자료가 아니며 가격·이미지 원본을 복제하지 않는다.

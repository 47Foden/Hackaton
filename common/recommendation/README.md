# 추천 점수 스냅샷

원본: 47Foden/Hackaton Pretuning 브랜치의 outputs/taste-only/*.csv.
정확한 원본 커밋은 source_commit.txt에 기록한다. 원본 CSV는 변경하지 않았다.

연결: 레몬 아이스티 → 레몬티, 말차라떼 → 녹차라떼. 기존 메뉴명 변경을 따라 임시로 점수를 재사용한다. 레시피가 다르다면 해당 메뉴 점수는 다시 평가해야 한다. API에서 고정 menu_id로 연결하고 행 누락·중복·범위 오류를 검사한다.

카페인 점수는 원본에 없다. 카페인 조건은 추정하지 않고 데이터 미준비를 안내한다. 가격과 판매 여부·제공 온도는 실시간 DB에서 읽는다.

# 45종 Pretuning 입력과 이진 행렬

- `binary.csv`: 실제 카탈로그에서 생성한 45행 × 12열의 분류 행렬(0/1).
- `catalogue.json`: 메뉴 ID·분류·옵션 프로필, 가격과 옵션 정의, 입력 지문.
- `metadata.json`: 현재 `prepared` 상태. OpenAI API 키가 없어 실제 맛 평가는 실행되지 않았다.

## 맛 평가 실행

저장소 루트에서 실행한다. `backend/.env` 또는 프로세스 환경의 `OPENAI_API_KEY`가 필요하다.

```powershell
python main.py --resume --model gpt-4.1 --output outputs/catalogue-45
```

매 회차 웹 검색과 구조화된 맛 평가를 실행한다(기본 5회, 총 10개 Responses 요청).
검색 근거와 전체 응답을 보존한다. 기본 시럽·토핑은 포함하고 추가 옵션은 제외한 레시피를 평가한다.
완료되면 `scores_1.csv`~`scores_5.csv`와 `continuous.csv`(45행 × 단맛/신맛/쓴맛)를 생성한다.
각 회차의 0~10 평가값을 10으로 나누고 5회 산술평균한다. 가격은 정규화하지 않는다.
이 작업은 모델 가중치 학습이 아닌, 검색 근거에 기반한 메뉴 속성 추정이다.

중단 후 동일한 명령으로 저장된 완료 회차를 재사용한다. 모델·입력 데이터가 달라지면 새 출력 폴더로 실행한다.
원래 11종 응답은 새 45종 평가로 재사용할 수 없다.

카페인 함량·우유 함량 등 출처가 없는 수치는 추정해 추가하지 않았다.
디카페인은 메뉴 분류이며 카페인이 0이라는 뜻이 아니다.
추가 옵션은 `catalogue.json`에 별도 저장하며, 맛 점수에 임의로 섞지 않는다.

## 서비스 반영

현재 서비스의 `common/recommendation/`은 기존 11종 점수 스냅샷을 유지한다.
45종 맛 평가 완료 후 서비스의 메뉴 ID 매핑·점수표 검증을 함께 확장해야 한다.
준비 단계의 이진 행렬만 복사하면 기존 추천 로더와 호환되지 않는다.

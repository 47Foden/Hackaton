# STT·45종 메뉴·LLM 통합 검증 기록

통합 기준은 기존 실험 브랜치 8136908과 origin/main baa4a2f다. 공유 직전 git fetch origin으로 모든 원격 브랜치를 다시 확인했고 main은 같은 커밋이었다. 음성 통합 브랜치 3fdee25의 변경은 이미 main에 포함돼 있었다. 팀원이 아직 push하지 않은 로컬 변경은 포함 여부를 알 수 없다.

## 실제 수행한 검사

- 사용자 PC의 별도 Docker 프로젝트에서 PostgreSQL migration·메뉴 API·주문 저장·FFmpeg 변환·음성 API·LLM 연결 등 51개 테스트가 31.468초에 통과했다. STT와 LLM 공급자 응답은 대체했으며 유료 API를 호출하지 않았다. 원래 개발 DB와 다른 DB/네트워크를 사용했다.
- 프론트 단위 테스트 18개 및 TypeScript/Vite 빌드 통과.
- Chrome 브라우저 테스트 25개가 외부 시험 서버 모드에서 48.2초에 통과했다. 45종 메뉴의 분류별 이름 표시, 음성 녹음 조작, LLM 후보·질문·자료 부족·오류 표시, 터치/음성 주문 완료를 확인했다. 메뉴·STT·추천 응답은 mock이며 실제 인식 정확도나 추천 품질을 뜻하지 않는다.
- 최신 분류 화면에 맞지 않던 과거 테스트 이동 경로와 Windows에서 없는 /tmp 스크린샷 경로를 수정했다. 제품 검증을 생략하거나 실패 응답을 성공으로 바꾸지 않았다.
- Windows의 자동 web-server 종료 대기 문제는 선택적인 외부 서버 시험 모드로 분리했다. 기본 설정은 기존 실행 방식을 유지한다.

## 여전히 확인하지 않은 사항

실제 마이크 발화→실제 Whisper 모델→유료 LLM까지 한 번에 실행하는 검사는 하지 않았다. 모델 파일과 전용 환경은 이번 작업에서 설치하지 않았다. 최신 45종 메뉴의 맛/성분 근거는 미확인 상태이므로 관련 취향 요청은 자료 부족이나 질문으로 이어질 수 있다. 예전 11종 제품 근거를 새 메뉴에 자동 복제하지 않았다.

기본 추천 방식은 existing이다. 운영자가 서버 환경에서 RECOMMENDATION_ENGINE=llm-direct를 켠 경우에만 추천 발화에 유료 LLM 호출이 발생한다. 메뉴명을 직접 말하는 주문과 STT는 팀 코드 흐름을 유지한다. 개발용 텍스트 입력 화면은 없다. 질문 이후 대화를 자동 기억하는 기능도 아직 없다.

현재 45종 기본 점수 추천의 continuous.csv는 팀 main에서 준비되지 않은 상태다. 이를 옛 11종 CSV로 채우지 않았으며 기본 방식은 자료 미준비 안내를 반환할 수 있다. 실제 맛 추천 배포 전에는 현재 메뉴용 근거 자료와 목표 방식 설정을 확인해야 한다.

이 기록은 서비스 전체의 정상 동작이나 사용자 만족도를 보장하지 않는다. 코드·DB 계약과 mock 연결에 대한 검증이며, 공유 후 각 환경에서 같은 커밋·DB 구조·STT 실행 경로를 맞춰야 한다. 개인 DB 파일이나 API 키를 팀원에게 보낼 필요는 없다.

# LLM 직접 추천 실험 버전 기록

각 버전은 같은 실험 브랜치의 별도 커밋으로 기록한다. 버전 이름은 실험 이력을 구분하며 서비스 배포 버전이나 품질 보장을 뜻하지 않는다. 실제 웹·음성의 기본 추천은 기존 CSV/규칙 경로를 유지한다.

## v1 — 개선 전 초안 (2026-11-09)

- 범위: 기존 경로와 분리된 LLM 후보 직접 선택, 텍스트 비교 CLI, 공식 메뉴 근거 자료, mock 테스트, 키 소유자가 직접 실행하는 소규모 실험 도구.
- 모델: gpt-5.4-mini-2026-03-17, reasoning none. 연결 확인 1회와 다섯 발화 각 1회, 총 6회.
- 결과: 다섯 발화 중 서버 검증 통과 1건. 가격 위반, 메뉴 ID 중복, 제외 조건 미확인으로 거부된 응답을 모두 보존했다. 이를 추천 정확도 20%로 해석하지 않는다.
- 총 비용 추정: USD 0.02487450. 기존 방식보다 낫다는 결론을 내리지 않는다. 반복 일관성은 미측정이다.
- 검증: 직접 추천/메뉴 근거/소규모 실행/mock/기존 추천 회귀 테스트 28개 통과. 실제 DB 메뉴 스냅샷으로 사용자가 API 실험을 실행했다.
- [결과 검토](2026-11-09-first-live/review.ko.md), [읽기용 결과](2026-11-09-first-live/results.ko.md), [원본 JSON](2026-11-09-first-live/results.json).
- 키 파일과 인증 헤더는 버전 관리 대상이 아니다. 기존 Pretuning/CSV/추천 함수, 웹·Whisper, 공용 Docker 설정은 변경하지 않았다.

## v2 — 아직 구현하지 않음

후보 단위 명확화, 미확인 정보 처리, 근거 연결, 확인 질문 및 정형 조건 검증 개선 등을 검토한다. v1 원본 결과를 덮어쓰지 않고 새 실행 결과를 별도 폴더에 저장하며, 변경점·모델/프롬프트·비용·개선 여부를 새 커밋에 기록한다. 추가 유료 실행은 별도 범위를 정한 뒤 진행한다.

# LLM 직접 추천 실험 버전 기록

각 버전은 같은 실험 브랜치의 별도 커밋으로 기록한다. 버전 이름은 실험 이력을 구분하며 서비스 배포 버전이나 품질 보장을 뜻하지 않는다. 실제 웹·음성의 기본 추천은 기존 CSV/규칙 경로를 유지한다.

## v1 — 개선 전 초안 (2026-11-09)

- 범위: 기존 경로와 분리된 LLM 후보 직접 선택, 텍스트 비교 CLI, 공식 메뉴 근거 자료, mock 테스트, 키 소유자가 직접 실행하는 소규모 실험 도구.
- 모델: gpt-5.4-mini-2026-03-17, reasoning none. 연결 확인 1회와 다섯 발화 각 1회, 총 6회.
- 결과: 다섯 발화 중 서버 검증 통과 1건. 가격 위반, 메뉴 ID 중복, 제외 조건 미확인으로 거부된 응답을 모두 보존했다. 이를 추천 정확도 20%로 해석하지 않는다.
- 총 비용 추정: USD 0.02487450. 기존 방식보다 낫다는 결론을 내리지 않는다. 반복 일관성은 미측정이다.
- 검증: 직접 추천/메뉴 근거/소규모 실행/mock/기존 추천 회귀 테스트 28개 통과. 실제 DB 메뉴 스냅샷으로 사용자가 API 실험을 실행했다.
- [결과 검토](2026-11-09-first-live/review.ko.md), [읽기용 결과](2026-11-09-first-live/results.ko.md), [원본 JSON](2026-11-09-first-live/results.json).
- 키 파일과 인증 헤더는 버전 관리 대상이 아니다. 기존 Pretuning/CSV/추천 함수, 웹·Whisper, 공용 Docker 설정은 변경하지 않았다.

## v2 — 근거·검증 보완 및 첫 실제 실험 (2026-11-09)

- 별도 v2 모듈에 후보 제한/재검증, ID 중복 구분, 온도별 정형 사실 및 근거 ID 검증, 서버 근거 구성, 질문/자료 보류를 구현했다. 기존 추천과 v1 모듈은 변경하지 않았다.
- 실험 프롬프트 direct-v2.2-researched는 full/llm을 기본으로 사용한다. 전체 메뉴와 공식 사실/추론을 구분한 감각 태그표를 보고 LLM이 해석·후보 선택·질문을 직접 판단한다. 초기 서버 질문 우선 초안은 guarded 비교 모드로 남긴다. 새 태그표는 독립 정답지가 아니며 숫자 점수로 순위를 계산하지 않는다.
- [새 개발용 발화 10개와 무료 검토](v2-dataset-review.md)를 추가했다. 평가 주석은 요청에 넣지 않고 별도 사실 점검에만 사용한다. mock을 정확도 점수로 제시하지 않는다.
- [메뉴 자료 재조사](v2-menu-research.md)로 v2.2 별도 근거/태그 스냅샷을 추가했다. 사실 기록 9개를 추가·수정하고 빈 태그 8칸을 추론으로 보완했다. 원래 자료와 v1 결과는 보존한다. 현재 CLI 기본은 조사본이고 사실 해시가 일치하는 태그표만 사용한다.
- [v2 설계 및 재현 방법](v2-design.md). 후보 사전 제한을 켜거나 끄는 eligible/full 모드를 구분하며 숫자 맛 점수는 사용하지 않는다.
- 서버 질문/보류 및 mock 응답은 실제 모델 성능으로 세지 않는다. v1 원본 결과를 덮어쓰지 않는다. 이후 실제 비교 결과는 별도 폴더에 보관한다.
- 키 소유자가 새 개발 발화 10개를 각각 1회 실행했다. 서버 검증 통과 2건(추천 1건·질문 1건), 거부 8건. 태그 ID 형식, fit 의미 혼동, 미확인 우유 제외 처리 문제가 관찰됐다. 검증 통과율은 추천 정확도가 아니다.
- 비용 추정 USD 0.115194, 평균 지연 2.656초. 입력 141166토큰·출력 2071토큰. 반복 일관성과 독립적인 취향 적합성은 미측정이다. 데이터셋과 제공 정보가 달라 v1 대비 개선을 입증하지 못했다.
- [실제 결과·실패 분석](2026-11-09-v2-live/review.ko.md), [읽기용 결과](2026-11-09-v2-live/results.ko.md), [원본 구조의 JSON](2026-11-09-v2-live/results.json). 공유본의 로컬 절대 경로만 치환했다. 원래 결과와 실패 응답을 성공으로 수정하지 않았다.
- 무료 코드 테스트 76개 통과는 검증·오류 처리 등의 소프트웨어 동작 확인이며 추천 성능 증거가 아니다. 현재 배포 품질로 판단하지 않는다. 후속 실험에서는 입력·응답 범위를 줄일 예정이다. 해당 축소 구현은 이 버전에 포함하지 않는다.
- 이 버전은 실험 공유용이며 운영 웹·음성의 기본값을 바꾸지 않는다. 추가 유료 호출은 실행하지 않았다.

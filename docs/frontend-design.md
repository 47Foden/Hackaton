# 프론트 디자인 기준

2026-11-07 사용자 결정: 앞으로 프론트는 [메가MGC커피 공식 메뉴 사이트](https://www.mega-mgccoffee.com/menu/)와 비슷한 브랜드 스타일로 구현한다. 로고·색상·제품 이미지와 메뉴 카드 표현을 참고하며, 기본 주문 흐름의 상단 안내·중앙 메뉴·하단 마이크 구조를 유지한다.

## 로고와 토큰

[common/brand_assets.json](../common/brand_assets.json)에 공식 원본 URL·확인일·로컬 경로·색상·글꼴을 기록했다. 로고 두 파일은 frontend/public/images/brand에 저장했다.

- 흰색 또는 노란색 바탕에서는 검은 로고 `/images/brand/mega-logo-dark.png`를 우선 사용한다.
- `/images/brand/mega-logo.png`는 공식 헤더의 다른 변형이다. 배경과 대비를 확인한 뒤 사용한다.
- 로고 비율은 유지하고 잘라내거나 색을 덧칠하지 않는다. 시작 화면 중앙에는 충분한 여백과 함께 배치하고 바로 아래 노란 주문하기 버튼을 둔다.
- 공식 CSS 확인값: 메인 노랑 #FDD000, 버튼 hover #FFDF43, 본문 #1C1C1B, 흰 배경 #FFFFFF, 테두리 #E0E0E0.
- 기본 글꼴은 Noto Sans KR을 우선하고 Noto Sans/Malgun Gothic/sans-serif를 대체 글꼴로 둔다. 글꼴 파일은 아직 포함하지 않았으므로 구현 시 로딩 방식과 대체 표시를 확인한다.

## 화면 적용 원칙

- 노란색 주요 버튼과 선택 강조, 검은 제목, 흰색 메뉴 영역을 기본으로 한다. 노란색 버튼에는 검은 텍스트를 사용한다.
- 메뉴 카드는 공식 음료 이미지·이름·가격 순으로 읽히게 하고, 이미지는 object-fit: contain으로 전체 컵이 보이게 한다.
- 선택한 카드/옵션은 색상과 체크 또는 선택 문구를 함께 표시한다. 가격과 메뉴명은 common을 기준으로 한다.
- 웹사이트의 작은 메뉴 링크 크기를 그대로 복제하지 않는다. 키오스크 본문은 20px 이상, 주요 조작은 높이 64px 이상을 출발점으로 실제 화면에서 검증한다. 이 크기는 프로젝트 제안이며 공식 사이트 수치가 아니다.
- 상단 안내, 중앙 간소화/전체 메뉴판, 하단 마이크가 겹치지 않게 한다. 중앙 전체 메뉴판의 확대 상태는 유지한다.
- 옵션·최종 확인·주문번호 화면에도 같은 색상과 글꼴을 사용한다. 페이지 이동과 음성 처리 상태는 명확한 텍스트로 표시한다.

## 자산과 준비 상태

| 항목 | 출처 / 위치 | 준비 상태 |
| --- | --- | --- |
| 로고 | 공식 헤더 원본, frontend/public/images/brand | 2종 확보. 검은 로고 시각 확인 완료 |
| 메뉴 이미지 | 공식 메뉴 원본, frontend/public/images/menus 및 common/menu_images.json | 14파일, 메뉴 11개·온도 16개 연결 완료 |
| 가격 | common/menu_prices.json 및 menu_price_sources.json | 11개 입력 완료. 매장 주문 페이지 기반, 에스프레소는 모바일쿠폰 가격 |
| 간소화 목록 | common에 선정 정보 없음 | 선정 전. API 명세대로 is_featured 기본 false, 선정 전에는 전체 메뉴 표시 |
| 브랜드 색상·글꼴 | 공식 CSS, common/brand_assets.json | 색상 확인 완료. 글꼴 로딩은 구현 시 결정 |
| 실제 주문 화면 | frontend/src | 후속 구현. 자산 확보와 화면 구현은 별개 |

로컬 자산은 프론트에서 /images/...로 참조한다. 기존 Docker 이미지에는 신규 public 자산 반영을 위한 재빌드가 필요하다. 공식 사이트 CSS 전체를 런타임 의존성으로 연결하지 않고 필요한 스타일을 프로젝트에서 구현한다.

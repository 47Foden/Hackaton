- 계획 8회 중 6회 요청, 모델 응답 5개 수신. 6번째 HTTP 429에서 자동 재시도 없이 중단했고 나머지 2회는 미실행이다.

- 입력은 응답당 약 3.2만 토큰이었다. 실제 429의 세부 원인은 기록된 정보만으로 확인할 수 없다. 키가 틀렸다고 판단할 근거도 없다.
